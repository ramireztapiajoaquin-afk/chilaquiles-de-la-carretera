# Chilaquiles de la Carretera

Sitio oficial del menú digital de **Chilaquiles de la Carretera**.

Incluye portada premium con video, menú conectado a Supabase, imágenes, videos, música, voz en off, carrito, pedidos por WhatsApp y panel de administración.

Este repositorio se usará para desplegar el sitio en Vercel sin cambiar la liga principal en cada actualización.
